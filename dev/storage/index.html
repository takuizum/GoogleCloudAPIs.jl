Cloud Storage API

GoogleCloudStorage wraps the GCS JSON API.

Client

GoogleCloudStorage.Client — Type
Client(project_id; creds=nothing, endpoint=nothing)

A Google Cloud Storage JSON API client.

If STORAGE_EMULATOR_HOST is set in the environment and endpoint is not provided, the client targets the emulator with no authentication.

Emulator

Set STORAGE_EMULATOR_HOST=http://localhost:4443 (or any http:// URL) before constructing a Client and it will skip authentication automatically.

Bucket operations

GoogleCloudStorage.Bucket — Type
Bucket

Metadata for a Google Cloud Storage bucket.

Fields: name, location (e.g. "US"), storage_class (e.g. "STANDARD").

GoogleCloudStorage.list_buckets — Function
list_buckets(client) -> PagedIterator{Bucket}

Iterate over all buckets belonging to the client's project.

GoogleCloudStorage.get_bucket — Function
get_bucket(client, name) -> Bucket
GoogleCloudStorage.create_bucket — Function
create_bucket(client, name; location="US", storage_class="STANDARD") -> Bucket

Create a new GCS bucket in the client's project.

GoogleCloudStorage.delete_bucket — Function
delete_bucket(client, name)

Delete a GCS bucket. The bucket must be empty.

Object operations

GoogleCloudStorage.Object — Type
Object

Metadata for an object stored in Google Cloud Storage.

Fields: bucket, name, size (bytes), content_type, generation.

GoogleCloudStorage.list_objects — Function
list_objects(client, bucket; prefix=nothing) -> PagedIterator{Object}
GoogleCloudStorage.get_object — Function
get_object(client, bucket, name) -> Object

Fetch object metadata (does not download the object body).

GoogleCloudStorage.download_object — Function
download_object(client, bucket, name) -> Vector{UInt8}
download_object(client, bucket, name, io) -> Nothing

Fetch the object body. The second form writes bytes into the provided IO.

GoogleCloudStorage.upload_object — Function
upload_object(client, bucket, name, data; content_type="application/octet-stream") -> Object

Simple (non-resumable) upload. data may be Vector{UInt8}, AbstractString, or IO. Uses uploadType=media — for large payloads, prefer a resumable upload (planned for v0.2).

GoogleCloudStorage.delete_object — Function
delete_object(client, bucket, name)

Delete an object from a bucket.

Example

import GoogleCloudStorage

gcs = GoogleCloudStorage.Client("my-project")

# Bucket lifecycle
bucket = GoogleCloudStorage.create_bucket(gcs, "my-bucket"; location="US")
println(bucket.name)

# Upload / download
GoogleCloudStorage.upload_object(gcs, "my-bucket", "hello.txt", "Hello World!")
bytes = GoogleCloudStorage.download_object(gcs, "my-bucket", "hello.txt")
println(String(bytes))   # "Hello World!"

# List objects under a prefix
for obj in GoogleCloudStorage.list_objects(gcs, "my-bucket"; prefix="logs/")
    println(obj.name, "  ", obj.size, " bytes")
end

# Clean up
GoogleCloudStorage.delete_object(gcs, "my-bucket", "hello.txt")
GoogleCloudStorage.delete_bucket(gcs, "my-bucket")
