# GoogleCloud2.jl

Welcome to the documentation for GoogleCloud2.jl!

This is a complete, Julia-native, high-performance client library for Google Cloud Platform.

## Modules
- **GoogleAuth**: Authentication via Application Default Credentials (ADC)
- **GoogleApiCore**: Foundation including Pagination and Retries
- **GoogleCloudStorage**: GCS Client
- **BigQuery**: High-throughput querying using Arrow
- **GoogleCloudPubSub**: PubSub messaging
